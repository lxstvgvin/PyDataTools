# PyDataTools

Простая программа на Python для обработки и анализа данных о продажах из CSV-файлов.

## Возможности

- Чтение данных из CSV-файлов.
- Проверка корректности входных данных.
- Пропуск строк с отсутствующими или некорректными значениями.
- Группировка продаж по товарам.
- Расчёт общего количества и выручки.
- Сохранение результатов в новый CSV-файл.
- Обработка распространённых ошибок при работе с файлами.

## Требования

- Python 3.
- Дополнительные библиотеки не требуются.

## Формат входных данных

Файл `sales.csv` должен содержать следующие столбцы:

```csv
product,quantity,price
Coffee,10,1200
Tea,5,800
Coffee,10,1200

## Запуск программы

Поместите файл sales.csv в папку проекта и выполните команду:

python main.py

## Результат работы
